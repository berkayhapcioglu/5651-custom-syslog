FortiGate

config log syslogd setting
    set status enable
    set server "SUNUCU-IP"
    set port 514
    set format default
end

Sophos: System services > Log settings > Syslog servers > Add (sunucu IP, port 514, Information). pfSense / OPNsense: Status > System Logs > Settings > Remote Logging. MikroTik: System > Logging > Actions > remote.

DHCP loglarını da gönderin: 5651 kapsamında hangi iç IP'nin kime verildiği de sorulur. Sunucu güvenlik duvarında 514/6514 portlarını sadece müşteri IP'lerine açın.
